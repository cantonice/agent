# 计算机视觉数据集画像

## 工作流程

1. 检查用户指定的实际数据目录、子目录、图像格式、标注格式、数据划分及类别配置（如 `classes.txt`、`data.yaml`）。保留配置中的类别 ID 顺序。优先使用本次指定路径的数据，明确统计的是物理样本，还是训练配置按重复路径指定的采样权重。默认按唯一图像文件路径统计物理样本，保留内容重复的文件。分组以实际用途为准，例如 BodySeg 的 `Dup/` 为重复样本存档。读取 manifest 时明确是否保留采样倍数。类别配置缺失时，以非负类别 ID 推导类别并注明。
2. 识别任务类型。YOLO 检测每行通常为 `class cx cy w h`，实例分割为 `class x1 y1 x2 y2 ...`。用实际配置与标注样本共同确认，任务类型一旦确定就按该任务解析所有标注行，例如分割任务中的两点标注属于异常行。OBB、关键点、独立栅格 Mask 使用相应任务语义。其他格式（如 COCO、OCR 文本、分类文件夹）按对应语义统计，不直接套用 YOLO 几何工具。
3. 对每个数据划分分别统计图像、标注文件、有效实例、类别数量及占比、每图实例数、缺失/空标注、孤立标注以及实际存在的 Mask 文件。无标注图片可能是合法负样本，结合任务语义判断；不能仅凭缺失或空文件认定漏标。
4. YOLO 数据优先运行 `scripts/profile.py`（相对本 Skill 目录）。先运行 `--help` 核对参数。依赖 Python 3、NumPy、Matplotlib、OpenCV、Pillow；本机已有 `/home/zhouzhen/miniconda3/envs/PCBA/bin/python` 可优先检查使用。其他环境按实际依赖选择。脚本不适用的目录结构或非 YOLO 格式，按下面口径实现等价统计。配对时保留图像和标签的镜像相对路径（如 `split/images`、`images/split` 或多批次子目录），独立的图像与标签根目录按实际配置映射；匹配歧义单独报告。
5. 按用户要求保存报告与图表，若未指定输出位置，默认在数据根目录下的 `statistics/`。必要时先生成至可写临时目录，确认最终输出权限后复制；保持原始数据和标注只读。核对 PNG 能正常打开、统计合计一致以及实际文件写入成功。

## 调用示例

```bash
python <skill目录>/scripts/profile.py --root /path/to/dataset --out /path/to/statistics --task segmentation --groups train val --hash-cross-groups
```

已知任务类型时指定 `--task segmentation` 或 `--task detection`，避免异常行影响自动识别。可指定 `--groups 主数据池=train 重复存档=Dup`，或省略分组让脚本识别 train/val/test。`--classes` 接受每行一个类别名、从 ID 0 起连续排列的文本文件；从 YAML 提取类别时核对映射，非连续 ID 按实际配置处理。脚本另输出机器可读的 `summary.json`，用其中已核对的数值生成文字报告。

## 标准统计口径与配图

- 以有对应图像的标签为实例统计基础，单独报告孤立标签数量。原始实例行数与有效实例行数分别记录。无效类别 ID、非有限数、坐标越界、分割顶点不足三个或坐标数量为奇数、多边形面积为零、外接框宽高为零及无效检测框单独计数，几何图使用有效实例。面积判定默认采用归一化鞋带公式绝对面积大于 1e-12 的基础几何检查。原始行数应等于有效行数加无效行数，非空标签与含至少一个有效实例的图片分别统计。明确任何裁剪、过滤、容差或采样策略。
- `01_class_instance_counts.png`：按类别统计有效实例数，显示准确数字、类别 ID；不同划分用一致类别顺序，若横轴独立需注明。报告最大/最小非零类别比例以及零样本类别。
- `02_mask_size_overlay.png`：对分割多边形按外接框中心对齐，实际填充多边形并累加覆盖率，分别展示相对原图尺寸及原始像素尺寸。不同划分使用共同尺度、颜色范围，像素视窗裁剪时注明超出比例；检测任务输出 `02_bbox_size_overlay.png`，使用 bbox 叠加并明确其含义。
- `03_object_center_distribution.png`：以外接框中心归一化至图像宽高，原点左上，网格热力图展示每格实例占本组实例数的比例。
- `04_width_height_joint_heatmap.png`：外接框宽高在归一化尺度和原图像素尺度上的二维分布，宽高变化跨度大时使用对数坐标；展示各自中位数，颜色表示每格占本组有效实例数的比例。
- `05_original_resolution_distribution.png`：读取原始图像文件头的宽高，统计所有可读图片（包括负样本），展示分辨率二维分布（每格占本组可读图片数的比例）和常见精确尺寸。
- 使用清晰中文图题及可读字体（例如已安装的文泉驿微米黑），静态图优先以 Matplotlib 保存 PNG。图表附统计口径；若没有有效实例，明确显示为空且保留图片规模统计。

## 数据质量检查

核对图像和标签配对是否唯一、类别是否合法、坐标与几何是否有效。若数据包含 `Mask/`，单独核对其文件配对情况，不把掩膜图作为原始图片计算。用户关注验证集泄漏时，对各划分图像计算文件内容 SHA-256，分别统计跨集重复内容组与涉及图片数，验证集泄漏比例使用验证集实际图片数作分母。相同文件哈希只能发现完全相同的文件；同图异标需比较相同内容组配对的标注，必要时标准化对象顺序后比较或人工复核，避免把多边形点顺序差异直接定为语义冲突。

## 交付

以中文简要提供数据规模表、类别分布表、目标宽高及面积中位数（注明 Mask 面积或 bbox 面积）、中心分布、常见分辨率、主要数据质量问题和生成文件链接。解释与数据任务相关的观察；对尚未验证的现象用推测措辞。按要求缩减或增加图表，不强制额外检查或变更数据。
